## Shared implementation gates

Each implemented method must identify its input/output contract, source, model/tokenizer revision, preprocessing, seed, dependencies, licence review, tests, deviations, and comparison protocol. A lightweight proxy score must not be labeled with a paper method's name. Model and dataset licences are reviewed separately from code licences.
