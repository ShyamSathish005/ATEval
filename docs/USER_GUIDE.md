# User guide

1. Start ATEval locally and open the Academic Humanizer.
2. Upload a `.tex`, LaTeX `.zip`, or `.txt` manuscript.
3. Inspect the section navigator and select editable passages.
4. Choose a revision objective, beginning with clarity or grammar for a
   conservative proposal.
5. Confirm the local model connection and request proposals.
6. Compare original and proposed text, including explanations and warnings.
7. Accept, reject, or manually edit proposals. Manual edits are revalidated;
   undo reverses the latest review decision.
8. Export only after selecting approved changes.

The imported source is not overwritten. Passages crossing protected LaTeX
markup or unsupported structures may be read-only. No-change and abstention
results are intentional safety behavior.
