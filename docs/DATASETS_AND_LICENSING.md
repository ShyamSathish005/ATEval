# Datasets and licensing

ATEval separates project-authored code from external research assets.

- Project-authored portions are covered by the repository MIT licence according
  to the owner's recorded confirmation.
- Python and npm dependencies, GitHub Actions, and fonts retain their upstream
  licences.
- IteraTeR-HUMAN and other research corpora require source- and
  revision-specific review. Raw data and derived experiment artifacts are not
  bundled in the public source archive.
- Model checkpoints are user-managed. ATEval does not automatically download
  or redistribute XtraGPT, IteraTeR, DistilBERT, or other weights.

See [DATASET_LICENSES.md](../DATASET_LICENSES.md),
[MODEL_LICENSES.md](../MODEL_LICENSES.md),
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md), and the
